shellf_

Raw shell, but idempotent, previewable, and fast.

One static binary. It pushes an ephemeral agent over SSH, evaluates your plan on the target, and vanishes.

the three guarantees a bare script never gives you

idempotent

Instructions observe first and skip when converged — re-run freely, drift-only changes.

previewable

--check shows what would change; status diffs current vs. desired. Nothing is touched.

fast

One connection, a resident agent evaluating on the host. No round-trips, no runtime to boot.

the language

An inventory, a plan, raw shell where you need it.

Instructions are defs written in shellf — a stdlib ships embedded. Drop to a raw shell block anytime; it's gated by the same contract.

hosts.shellf
defaults = { user: "deploy" }

host web1 = { address: "10.0.0.1", role: "edge" }
group web  = [web1]
site.shellf
on web {
    apt.install("nginx")
    template("nginx.conf", "/etc/nginx/nginx.conf")
    service("nginx", "true", "true")   # running, enabled

    # raw shell — still gated by the same contract
    if !shell { nginx -t } {
        service-reload("nginx")
    }
}

how it works — no control plane, no daemon, no state file

01 · push

The binary uploads itself as an agent over SSH, cached by content hash — a second run skips the transfer.

→ssh
02 · evaluate

It reads the plan on the host, observes real state, applies only the drift. Secrets stay on tmpfs.

→ttl
03 · vanish

The resident agent self-erases after its idle window. Nothing stays installed.

in the box

▸Per-host templating

@{var} rendered per host from inventory vars — no clash with a config's own ${…}.

▸Secrets, off disk

--secret-file/--secret-env, redacted everywhere, deposited on a RAM-backed tmpfs.

▸Modules

Local imports and hash-verified remote git modules, pinned by a shellf.lock.

▸ssh-agent auth

Keys never leave your agent; an inventory key: is an optional override.

▸Loops & overrides

Parse-time for over a list, and per-call with { } variable overrides.

▸One static binary

Agentless, linux/amd64, zero runtime on the target.
