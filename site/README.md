# site

The shellf landing page — a single standalone `index.html` (inline CSS, no build,
no dependencies) plus `favicon.svg`. Destined for **shellf.org**.

Preview locally: open `index.html`, or `python3 -m http.server` from this directory.

Deploy: serve this directory as static files (GitHub Pages, or any static host)
behind the shellf.org domain. Theme follows the visitor's `prefers-color-scheme`.
